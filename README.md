# Tim Maundu Portfolio

Static GitHub Pages portfolio for Tim Maundu, an AI Systems Builder helping businesses run their systems with reliable AI agents.

Live site: <https://timmaundu.github.io/>

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server.

## Deployment

Publish this repository as `timmaundu.github.io` and enable GitHub Pages from the `main` branch root.
