01 — about

Engineer. Builder. Problem-solver.

I write code, run servers and own the outcome — from the first SQL table to the last dashboard widget.

// since 2017

I’m a full-stack software engineer from Kenya who likes building software that makes real work easier. Not demos, not tutorials — systems that people depend on after the launch party: billing that reconciles correctly, payments that clear on time, dashboards that tell the truth.

My main hands-on project is MUATIM, a live ISP billing & payments platform (the codebase snapshot in this very repo). It handles M-Pesa payments end-to-end, customer management, package billing, network operations and automation for internet providers — plus the provisioning tooling that rolls it out to production servers and routers.

“Software that removes friction beats software that adds features.” — a principle I code by

I work close to the problem: local payment rails, uneven connectivity, growing teams and operations that need clear accountability. That’s what makes software useful — and what keeps me building.

flagship · live product muatim.co.ke

MUATIM — ISP billing & payments platform

A complete billing system for internet service providers, built around how money actually moves in Kenya. Handles customer lifecycle, packages and billing — with M-Pesa payments collected, verified and reconciled automatically.

  • M-Pesa STK Push payments with automatic callback reconciliation
  • Customers, packages, billing cycles & payment history in one place
  • Network operations: MikroTik routers, hotspot/PPPoE & voucher flows
  • Admin panels, mobile-friendly customer tools & scheduled automation
